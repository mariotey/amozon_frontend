About the Project

Amozon is a data science and machine learning engineering portfolio project. Shopper 1, Shopper 2, and Shopper 3 each represent a different anonymized profile from the review dataset. Switching shoppers changes whose reviews and recommendations you see.

How the store chooses products

  1. Patterns in shopper ratings. Collaborative filtering (ALS) learns patterns across user ratings.
  2. Similar product descriptions. If the first approach has no usable picks, content-based filtering (TF-IDF) uses product text and positive reviews.
  3. Popular picks. If neither approach produces picks, the store falls back to popular products.

These are fixed example shoppers, chosen to demonstrate each scenario. The backend still follows this order automatically; model or data updates may change which approach a shopper receives. Each approach is documented and evaluated separately in its own notebook.

About the Data Used

The project uses the first 5% of review records from the Software category of Amazon Reviews 2023, with matching product information. This is a historical slice, not a random sample or a complete purchase history. Prices are historical, and the models do not learn while you browse.

The notebooks use earlier reviews for training and later reviews for validation and testing. They report how well each approach retrieves and ranks relevant products, along with the users and products it cannot support. These results do not measure actual purchases or sales.
